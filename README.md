Hi5 Calendar App - Group Project Submission

HOW TO RUN:
1. Ensure you have Java 21 (or newer) installed.
2. This application uses JavaFX. Ensure JavaFX libraries are available.
3. If using an IDE (IntelliJ/Eclipse):
   - Import the 'src' folder as sources.
   - Run 'CalendarGUI.java' as the main class.
   - Ensure VM options are set if required by your JavaFX version.

FILE STRUCTURE:
- src/: Contains all source code (.java files).
- data/: The app will automatically create this folder and the .csv files if they don't exist.

FEATURES IMPLEMENTED:
- Calendar Grid View (Month/Week/Day)
- Recurring Events (Daily/Weekly/Monthly/Yearly)
- Exception Handling (Delete single instance of recurring event)
- Advanced Search (Date range, keyword, category, location, attendees)
- Backup & Restore (Single-file .bak with Append/Replace options)
